# Plug and Play Agent Template

Use this if you want to build something but are not sure how to start. Fill in the blanks, then paste the whole thing into the Claude Code panel.

---

## Fill in the blanks

```
I want to build an agent that helps my business. Here is what it should do:

WHAT MY BUSINESS DOES:
I run a [type of business, e.g. "physiotherapy clinic", "accounting firm", "online retail store"].

THE PROBLEM I WANT TO SOLVE:
Every [day/week/month], I spend too much time [describe the repetitive task, e.g. "manually checking my inbox for urgent client requests and writing follow-up emails"].

THE THREE PARTS OF MY AGENT:

Trigger: Start this agent [when something happens, e.g. "every morning at 8am" / "when a new file appears in a folder" / "when I run it manually"].

Task: When it runs, it should [what it does, e.g. "read my notes file, find anything marked URGENT, and create a short list"].

Output: Then it should [what happens with the result, e.g. "print the list to the terminal" / "save it to a file called todays-summary.txt" / "send it to me by email"].

KEEP IT SIMPLE:
Start with the simplest version that would still be useful. I am not a developer. Plain Python, no frameworks.

Please create:
1. The main Python script
2. Any folders or example files it needs
3. A short README.md explaining how to use it
```

---

## How to use this

1. Copy everything between the triple backticks above
2. Replace all the `[bracketed sections]` with your real information
3. Paste the whole thing into the Claude Code panel
4. Read what Claude says it will do, then click Allow
5. Open the terminal and run the script Claude created

---

## If it does not work on first run

Paste the error into Claude Code:

```
When I ran the script I got this error:

[paste the error message here]

Please fix it.
```

Claude will correct it. This is normal. Keep going.
