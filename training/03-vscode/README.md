# Module 3 — Welcome to Your VS Code Workspace

You are now inside VS Code — a free tool that lets you build software. You do not need to write any code today. Your job is to describe what you want in plain English. Claude Code does the building.

## What you are looking at

### Left sidebar — the Explorer
The folder tree on the left shows two workspaces:

- **shared/** — read-only training materials (these files)
- **student/** — your personal workspace where you build things

### Left sidebar — the Claude Code panel
Look for the **asterisk (*) icon** near the top of the left sidebar. Click it.

This is the Claude Code panel. It is a conversation window — just like a chat. Type what you want built, and Claude responds with code, files, or questions. You review and approve before anything runs.

### Bottom — the Terminal
Press `` Ctrl+` `` (backtick, below Escape) to open a terminal. You can run files here. Your instructor will show you how in Module 4.

---

## The key difference from Claude UI

In Module 2 you used Claude at claude.ai. That gives you **answers** — text, drafts, summaries.

Claude Code gives you **actions** — it can:
- Create and edit files in your workspace
- Run scripts on a schedule
- Connect to other services (email, spreadsheets, APIs)
- Build something that runs without you touching it

The conversation is the same. The capability is much larger.
