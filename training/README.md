# Welcome to Your AI Agent Training Environment

This is your private workspace, set up just for this session.

## Two folders in your Explorer

Look at the left sidebar. You will see two folders:

**shared/** — Training exercises, guides, and templates. Read-only. Your instructor will tell you which file to open for each exercise.

**student/** — Your personal workspace. Everything you build here is yours to keep. It is backed up automatically so you will still have it after today.

## How to read these files

Click any `.md` file to open it. Press `Ctrl+Shift+V` (or `Cmd+Shift+V` on Mac) to see it as a formatted document instead of raw text. Press it again to toggle back.

## The Claude Code panel

Look for the **asterisk (*) icon** in the left sidebar — that is the Claude Code panel. This is where you type requests in plain English and Claude builds things for you. You do not need to write code. You describe what you want, and Claude writes it.
